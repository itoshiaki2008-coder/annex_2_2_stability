計算手順（附属書[2-2] 第2項）
1
小安則第8章で求めた旅客定員の数を②式の n に代入してFの値を求め、このnの値とFの値を①式に代入し、同式を満足するか確認する。
2
(1)で①式を満足しない場合には、②式のnの値を適当に減じた場合のFの値を求め、このnの値とFの値を再度①式に代入して確認する。
3
(2)によっても①式を満足しない場合は、①式を満足するまでnを減じながら(2)の方法を繰り返す。
4
旅客搭載場所が2層以上の場合、h = (n₁h₁+n₂h₂+…)/(n₁+n₂+…) で加重平均算定。n₁,n₂,… は想定される最も厳しい場合のものとする。
5
最大搭載人員 ＝ 計算で求めたn ＋ 操縦者1人 ＝ n+1人とする（第3項）。
①式（復原性条件）
M ≥ (n/100) × (7.5 + 7.5h − 13.1d + 1.4B̄·B / (2F)) … ① M = M₀ − Wc(Hc − 1.75d₀) M₀ = Wℓ / tan θ　（傾斜試験） d = d₀ + Wc / (0.78LB) Wc ：搭載する貨物の質量（t） Hc ：キール上面から貨物の重心まで（m）
②式（乾げん補正）
F = f − 0.096 × (n / LB) … ② 　　ただし B/5.5 より大となるときは B/5.5 の値とする f = f₀ − Wc / (0.78LB) f₀ ：傾斜試験時の乾げん（m）
③式（沿海区域用 定員上限）
n ≤ LB(F₁ − f) / 0.096 − 1 … ③ F₁ ：人を搭載しない状態における最小乾げん（m）
n 上限（F₂ 喫水条件）
n ≤ (F₂ − 0.025L) × LB / 0.33 − 1 F₂ ：人を搭載しない状態での船尾の最小乾げん（m）
